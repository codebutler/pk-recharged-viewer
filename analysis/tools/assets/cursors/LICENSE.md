# Pixelarticons SVG/PNG cursors

Source: https://pixelarticons.com/free/svg-cursors/ (PNG files fetched from
https://pixelarticons.com/free/cursors/<name>.png on 2026-08-19).

Author: Gerrit Halfmann (halfmage) — https://github.com/halfmage/pixelarticons

License: MIT. The pixelarticons project is MIT-licensed; the site distributes
this cursor set free and encourages self-hosting.

All 51 PNGs (32x32, light + dark variants) are vendored so the full set is on
hand; generate_page.py currently embeds default / pointer / zoom-in / zoom-out
as data URIs (hotspots computed from the opaque-pixel geometry: arrow tip 6,4;
pointer fingertip 12,4; zoom lens center 14,14).
